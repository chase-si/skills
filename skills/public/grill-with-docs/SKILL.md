# Grill with Docs

Read the shared [interview rules](../grill-me/INTERVIEW.md) before asking
questions. Follow those rounds, numbering, recommendations, selectable UI, and
completion criteria within this invocation; do not try to invoke the user-only
`grill-me` entrypoint.

Load the `domain-modeling` skill with the environment's skill-loading tool, or
read [its instructions](../../coding/domain-modeling/SKILL.md) when no such tool
is available. Apply it throughout the interview: resolve the project's glossary
and ADR locations, record settled terms inline, and offer ADRs for qualifying
decisions. Keep existing `CONTEXT.md` projects compatible.
